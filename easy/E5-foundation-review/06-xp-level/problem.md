# XP Level

**Level:** E5 · **Type:** Application
**Concepts:** division, modulo, arithmetic

## Prompt
For an XP total, print its one-based level and XP remaining until the next 100-XP level.

## Input
One nonnegative integer: xp.

## Output
`Level L, R XP to next`

## Examples

### Example 1
Input:
```text
250
```
Output:
```text
Level 3, 50 XP to next
```

### Example 2
Input:
```text
0
```
Output:
```text
Level 1, 100 XP to next
```

### Example 3
Input:
```text
300
```
Output:
```text
Level 4, 100 XP to next
```

## Constraints and edge cases
Follow the stated input constraints and match output text, capitalization, spacing, and decimal precision exactly.

## Hint
Integer division finds the completed 100-XP blocks.
