# Countdown

**Level:** E5 · **Type:** Application
**Concepts:** division, modulo

## Prompt
Convert a day count into whole weeks and remaining days.

## Input
One nonnegative integer: days.

## Output
`W weeks, D days`

## Examples

### Example 1
Input:
```text
17
```
Output:
```text
2 weeks, 3 days
```

### Example 2
Input:
```text
7
```
Output:
```text
1 weeks, 0 days
```

### Example 3
Input:
```text
6
```
Output:
```text
0 weeks, 6 days
```

## Constraints and edge cases
Follow the stated input constraints and match output text, capitalization, spacing, and decimal precision exactly.

## Hint
Use division for weeks and modulo for days.
