# Grade Calculator

**Level:** E5 · **Type:** Application
**Concepts:** conditionals, comparisons

## Prompt
Convert a numeric score to A, B, C, D, or F using 90, 80, 70, and 60 cutoffs.

## Input
One integer: score.

## Output
One letter grade.

## Examples

### Example 1
Input:
```text
85
```
Output:
```text
B
```

### Example 2
Input:
```text
90
```
Output:
```text
A
```

### Example 3
Input:
```text
59
```
Output:
```text
F
```

## Constraints and edge cases
Follow the stated input constraints and match output text, capitalization, spacing, and decimal precision exactly.

## Hint
Test scores from highest cutoff downward.
