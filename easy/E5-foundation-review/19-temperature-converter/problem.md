# Temperature Converter

**Level:** E5 · **Type:** Application
**Concepts:** `double`, arithmetic, fixed formatting

## Prompt
Convert Celsius to Fahrenheit and Kelvin.

## Input
One floating-point number: Celsius.

## Output
Two fixed two-decimal lines.

## Examples

### Example 1
Input:
```text
0
```
Output:
```text
Fahrenheit: 32.00
Kelvin: 273.15
```

### Example 2
Input:
```text
100
```
Output:
```text
Fahrenheit: 212.00
Kelvin: 373.15
```

### Example 3
Input:
```text
-40
```
Output:
```text
Fahrenheit: -40.00
Kelvin: 233.15
```

## Constraints and edge cases
Follow the stated input constraints and match output text, capitalization, spacing, and decimal precision exactly.

## Hint
Fahrenheit is Celsius times 9/5 plus 32.
