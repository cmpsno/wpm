# Tip Calculator

**Level:** E5 · **Type:** Application
**Concepts:** `double`, arithmetic, fixed formatting

## Prompt
Split a bill plus tip equally among a party.

## Input
Bill amount, tip percent, and positive party size.

## Output
`Total per person: X.XX`

## Examples

### Example 1
Input:
```text
100.00 20 4
```
Output:
```text
Total per person: 30.00
```

### Example 2
Input:
```text
10.00 15 2
```
Output:
```text
Total per person: 5.75
```

### Example 3
Input:
```text
9.99 0 3
```
Output:
```text
Total per person: 3.33
```

## Constraints and edge cases
Follow the stated input constraints and match output text, capitalization, spacing, and decimal precision exactly.

## Hint
Use fixed formatting with two decimal places.
