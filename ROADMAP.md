# C++ Curriculum Roadmap

The curriculum moves from hello world to idiomatic C++ through recognition, recall, and application. Every problem is a single C++17 file with stdout-based tests.

## Foundation

- [x] E0 — Hello, World & Compilation (10 problems)
- [ ] E1–E4 — Variables/I/O, conditionals, loops, and functions (10 problems each)
- [ ] E5 — Foundation review (20 mixed application problems, after E0–E4; Easy total: 70)

## Numbered steps

- [ ] Step 1 — Collections: arrays, strings, and vectors (detailed after the foundation)
- [ ] Step 2 — Structured Data: `struct`, references, and pass-by-reference (placeholder)
- [ ] Step 3 — Classes & Memory Basics: classes, constructors, and stack/heap (placeholder)
- [ ] Step 4 — STL & Problem Patterns: maps, sets, sorting, searching, and common patterns (placeholder)
